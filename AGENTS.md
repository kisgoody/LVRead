# LVRead Project Guidance

## UI Motion

For every task that creates or modifies code under `LVRead/LVRead/UI`, load and follow `$lvread-motion` before editing. Implement useful animation as part of the change when it clarifies feedback, state, hierarchy, or spatial continuity. Do not add animation to pure data, parser, repository, network, persistence, localization, or documentation work unless the task directly changes a user-visible UI state.
