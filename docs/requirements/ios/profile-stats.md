# 我的与阅读统计需求（iOS）

## 1. 文档定位

本文是 LVRead iOS“我的—阅读概览”和“阅读统计”的统计口径、页面结构、数据删除、导入与导出规范。实现以本文为准；阅读建议的规则和话术仍以 `reading-advice.md` 为准。

当前阶段不做账号体系，不依赖服务端，全部数据保存在本地。统计结果只能描述用户自己的阅读行为，不评价阅读快慢、能力或效率。

## 2. 核心术语与公式

| 名称 | 定义 |
|---|---|
| 阅读有效时长 | 阅读页位于前台、页面可见、菜单和设置关闭、未听书，并且距离最近一次操作不足 2 分钟的累计时间 |
| 有效阅读字数 | 用户在有效阅读状态下实际经过的正文文本范围，按当前字数规则统计 |
| 阅读页数 | 用户在有效阅读状态下实际经过的排版页数，同一阅读控制器生命周期内相同页面不重复累计 |
| 阅读节奏 | `有效阅读字数 × 60 ÷ 同口径有效阅读秒数` |
| 连续阅读 | 按现有 `ReadingAnalytics` 连续日期规则计算，不因新增阅读节奏改变 |

阅读节奏必须使用秒级原始值计算，不能先把时间四舍五入为分钟。周期阅读节奏使用周期总字数除以周期总秒数，禁止对每日节奏求算术平均。

```text
周期阅读节奏 = 周期有效阅读总字数 × 60 ÷ 周期同口径有效阅读总秒数
```

### 2.1 阅读节奏展示规则

| 条件 | 展示 |
|---|---|
| 同口径有效时间 ≥ 60 秒且有效字数 > 0 | 四舍五入显示整数，例如 `263 字/分钟` |
| 同口径有效时间不足 60 秒 | `--`，详情提示“数据不足” |
| 有效时间为 0 或有效字数为 0 | `--` |
| 只有旧阅读时间、没有新字数口径 | `--`，不得混算 |

中文界面统一使用“字/分钟”。英文界面显示 `words/min`。英文正文的“字数”实际按单词计数，因此中英混合的全局节奏是个人趋势指标，不用于跨语言比较。

## 3. 阅读有效时长规则

### 3.1 开始或恢复计时

以下条件必须同时满足：

1. App 处于前台活动状态；
2. 阅读页面已显示在窗口中；
3. 阅读菜单未打开；
4. 阅读设置、目录等模态页面未打开；
5. 听书未播放且未暂停；
6. 距离最近一次阅读页触摸、拖动或页面恢复活动不足 120 秒。

进入阅读页、App 回到前台、阅读页触摸或拖动均刷新最近活动时间。该判断是“活跃阅读推断”，不调用摄像头，也不声称确认用户眼睛正在注视屏幕。

### 3.2 暂停计时

以下任一事件发生时立即结算并暂停：

- App 进入后台、失去活动状态或屏幕锁定；
- 阅读页面离开窗口；
- 打开中央阅读菜单；
- 打开阅读设置、目录或其他模态页面；
- 听书成功开始；
- 距离最后一次操作达到 120 秒。

两分钟无操作时，计时截止到“最后一次操作时间 + 120 秒”。之后只有新的阅读页交互才能开启新的有效阅读区间。

## 4. 有效阅读字数规则

字数来自用户实际经过的页面文本范围，不使用整本书字数，也不使用 Unicode 字符总数代替英文词数。

### 4.1 中文及混合文本

- 汉字逐字计数；
- 拉丁字母组成的英文内容按单词计数；
- 数字序列计 1；
- 空格、换行、纯排版符号和标点不计；
- Emoji、控制字符和 HTML 标签不计。

### 4.2 英文词规则

| 示例 | 计数 |
|---|---:|
| `hello` | 1 |
| `state-of-the-art` | 1 |
| `don't` | 1 |
| `U.S.A.` | 1 |
| `1,000` | 1 |
| `3.14` | 1 |

### 4.3 采集边界

- 只有阅读有效时长正在计时的页面经过事件才累计页数和字数；
- 听书自动翻页不累计有效阅读页数和字数；
- 菜单、设置和空闲暂停期间不累计；
- 主题、字号、边距变化引发的页面刷新不能重复累计；
- 图片型 PDF、漫画或无法提取正文的页面可以累计有效阅读时间和页数，但不参与阅读节奏分母，阅读节奏显示 `--`。

## 5. 页面信息架构

### 5.1 “我的—阅读概览”

定位为快速查看今日和累计状态，不重复展示完整趋势或阅读建议。

四宫格：

1. 今日有效阅读；
2. 今日阅读节奏；
3. 累计有效阅读；
4. 连续阅读。

四宫格下方显示：`今日经过 X 字 · X 页`。底部入口为“查看详细阅读统计”。阅读建议只在阅读统计页展示。

### 5.2 阅读统计页

内容顺序：

1. 累计概览：累计有效阅读、累计页数/字数、整体阅读节奏、连续阅读；
2. 最近 7 天摘要：有效分钟、有效字数、阅读节奏；
3. 单日阅读：按小时展示有效分钟曲线，日期详情包含分钟、页数、字数和节奏；
4. 阅读节奏：最近 7 天/全部的每日趋势，点击数据点查看日期、有效分钟、字数和节奏；
5. 阅读时间分布：0–23 时累计有效分钟柱状图，详情包含分钟、页数、字数和节奏；
6. 常读书籍：按累计有效阅读时长排序，显示书籍有效时长和节奏，不按节奏排名；
7. 文件格式分布：统计当前书架 TXT、EPUB、PDF 等实际支持格式；
8. 阅读建议：按阅读频率、时间分布、连续性和休息影响生成，不使用阅读节奏评价快慢。

“最近 7 天”包含今天；全部数据不超过 7 天时，“全部”不可点击。无同口径节奏的日期不绘制为 0，趋势图应断开或显示无数据。

## 6. 数据存储与派生规则

持久化原始统计，不持久化计算后的阅读节奏：

- 累计有效阅读秒数；
- 每日有效阅读分钟（兼容现有统计）；
- 每小时有效阅读秒数；
- 每小时阅读节奏同口径秒数；
- 每日和每小时页数；
- 每日和每小时有效字数；
- 单本书有效阅读秒数、节奏同口径秒数、页数、字数和最后阅读时间；
- 字数规则版本。

“我的”、阅读统计图表、详情和导出文档必须调用同一阅读节奏公式。删除某日记录时，必须同步删除该日期的时间、节奏秒数、页数和字数，并刷新所有派生结果。

字数规则版本升级时，无法可靠换算的旧字数和单本书字数必须清除；旧有效阅读时长和页数保留。旧时间不得与新字数混算阅读节奏。

旧版本的单本书累计时长和页数没有日期维度，无法可靠回填到具体日期，因此删除升级前的历史日期时，只能精确回扣全局日/小时统计；从本版本开始产生的单本书按日明细可完整回扣，并同步刷新常读书籍。禁止用比例估算旧书籍明细。

## 7. Markdown 全量导出规范

导出文件名：`LVRead-Reading-Stats.md`。导出全部现存统计，不限制最近 30 天。

### 7.1 人类可读内容

| 区块 | 内容 |
|---|---|
| 统计总览 | 导出时间、记录天数、累计有效时长、总页数、总字数、整体节奏、最近 7 天摘要、小时记录数 |
| 统计规则 | 有效时长、有效字数、阅读节奏、页数及字数规则版本 |
| 每日统计 | 日期、有效时长、页数、字数、阅读节奏、活跃时段数 |
| 24 小时累计分布 | 每小时累计有效时长、页数、字数和节奏 |
| 逐日小时明细 | 每个日期每小时的秒数、页数、字数和节奏 |
| 文件格式分布 | 当前书架全部格式及书籍数量 |
| 常读书籍 | 全部有统计的在架书籍标识、真实书名、有效时长、页数、字数和节奏 |

常读书籍按有效时长降序导出，不限制前 5 本。书籍名称优先使用真实元数据标题，禁止展示文件哈希作为可读书名。

### 7.2 机器导入数据

Markdown 末尾必须保留 `LVREAD-STATS:1` 标记和 `lvread-stats-data` Base64 数据块。机器数据包含全部时间、节奏秒数、页数、字数、规则版本及日期/小时明细。

文件格式分布和常读书籍为当前书架派生的人类可读统计，不写回阅读历史；导入统计文件不会创建或覆盖书架书籍。

### 7.3 导入兼容

- 校验格式名、版本、日期键、小时键和所有数值非负；
- 旧文件缺少页数、字数或节奏秒数字段时按空数据处理；
- 旧字数规则版本的字数不导入，时间和页数仍可导入；
- 日期重复时由用户选择保留现有记录或覆盖重复日期；
- 覆盖和删除后，所有页面和图表必须基于原始数据重新计算。

## 8. 页面状态与无障碍

| 状态 | UI 要求 |
|---|---|
| 有统计 | 展示完整概览、趋势、分布和建议 |
| 无统计 | 数值显示 0，阅读节奏显示 `--`，图表显示“暂无同口径数据” |
| 不足 60 秒 | 阅读节奏显示 `--`，详情显示“数据不足” |
| 导入失败 | 不修改现有统计，提示文件不符合规范 |
| 删除失败 | 保留当前界面和本地数据，不显示已删除状态 |

所有卡片适配阅读主题、深色模式和 Dynamic Type。图表详情必须提供 VoiceOver 标签；阅读节奏不能仅依靠颜色表达。

## 9. 验收标准

- 打开菜单、设置、目录或听书后不累计阅读有效时长、有效页数和有效字数；
- 两分钟无操作后只统计到最后操作后的第 120 秒；
- 阅读节奏按秒计算，`8420 字 ÷ 1920 秒` 显示 `263 字/分钟`；
- 少于 60 秒、字数为 0 或缺少同口径数据时显示 `--`；
- 周期节奏使用总字数除以总秒数，不平均每日节奏；
- 删除单日统计后，单日图表、节奏趋势、时间分布和导出内容同步变化；
- Markdown 导出包含全部历史、统计规则、每日/小时/格式/书籍数据和机器数据块；
- 旧导出文件仍可导入，旧字数不污染新阅读节奏；
- 所有主题下卡片、文字、图表和分段控件可读，触控区域不小于 44pt。
